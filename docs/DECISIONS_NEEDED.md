Signing secrets, known bootstrap credentials, session revocation after password change, CSRF/rate limits and cookie/deployment verification remain open.

- D09: No application startup, live DB operation, migration or deployment was run. Existing startup cleanup/bootstrap and memory fallback remain risks. Approval gates and rollback are documented in AUTHORIZATION.md.
